# Security

## Report a vulnerability

Do not open a public issue for a vulnerability. Use the private vulnerability report of
GitHub ("Security" tab, "Report a vulnerability").

Give the steps to reproduce the problem and the version or commit.

## Scope

- Access control of rooms, projects, scenarios and notes.
- Data that a user from one org can see in another org.
- Injection in SQL or in the page.
- Personal data in the audit table or in the API responses.
